# Nexus Automations - Reglas de Operación del Workspace

Este proyecto corresponde a una **Agencia de Creación de Automatización** especializada en:
1. **SAP Integration Suite**: Cloud Integration (CPI), SAP BTP, S/4HANA OData, RFCs, BAPIs y scripts Groovy.
2. **Business Process Management (BPM)**: BPMN 2.0, Camunda, SAP Build Process Automation, aprobaciones humanas y SLAs.
3. **Chatbots Inteligentes**: Asistentes omnicanal para corporativos y PyMEs (WhatsApp Cloud API, Telegram, Web), integrados con CRM y RAG.
4. **Experiencia Web & Portal**: Sitio web moderno, calculadoras de ROI y showcases interactivos.

## Reglas Mandatorias para todos los Agentes y Subagentes

1. **Protocolo de Fiscalización Obligatoria**:
   - Todo trabajo producido por cualquier agente (`automation-director`, `sap-integration-architect`, `bpm-workflow-engineer`, `chatbot-solutions-developer`, `agency-web-designer`) debe ser auditado por **`lead-quality-auditor`**.
   - Si se detecta cualquier error, inconsistencia o vulnerabilidad de seguridad, `lead-quality-auditor` tiene la potestad de aplicar la corrección de forma autónoma inmediatamente.

2. **Convenciones de Código y Estilo**:
   - HTML5 semántico con accesibilidad y diseño responsive.
   - Scripts Groovy e iFlows con manejo explícito de errores (`Exception Subprocess`).
   - Cero credenciales o secretos en texto plano; referenciar almacenes de claves seguros (Keystores o variables de entorno).
   - Documentación concisa en Markdown en cada entrega.
